# README Path

Use this path when creating, refreshing, or reviewing a `README.md`.

## Read First

- package metadata such as `pyproject.toml`, `package.json`, or equivalent
- entrypoints and CLI help text
- installation or environment setup files
- nearby docs that the README should link to

## Required Outcome

A good README should answer, in this order:

1. What this project is.
2. Why it exists or what problem it solves.
3. How to reach first success quickly.
4. Where deeper documentation lives.

## Recommended Sections

- project summary
- quick start
- installation or setup
- core usage
- configuration basics
- links to deeper docs
- contributing notes only if the repository uses them

## Validation Points

- project name and purpose match the repository
- quick-start commands are real and current
- linked paths exist
- README acts as a hub instead of duplicating long docs
- setup steps do not omit critical prerequisites
