# Onboarding Guides Path

Use this path when helping a new contributor or operator become productive in a
real repository.

## Read First

- setup files and environment requirements
- developer tooling and local commands
- the most common workflows
- docs that explain ownership, conventions, or support channels

## Recommended Sections

- who this guide is for
- environment setup
- first successful workflow
- key systems and how they connect
- common daily tasks
- where to ask for help or find deeper docs

## Validation Points

- setup steps are complete enough for a new person
- required tools and versions are explicit
- workflow examples match actual repository commands
- the guide points readers to the right next docs
