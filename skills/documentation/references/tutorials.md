# Tutorials Path

Use this path when teaching a newcomer through one successful learning flow.

## Read First

- setup instructions
- the smallest runnable example in the repository
- tests or examples that prove the happy path

## Writing Rules

- teach one path from start to finish
- state prerequisites explicitly
- use ordered steps
- include checkpoints so the reader knows success happened
- keep branching and optional choices to a minimum

## Recommended Sections

- goal
- prerequisites
- step-by-step lesson
- expected result
- next steps

## Validation Points

- each step is possible with the repo as it exists
- commands and paths are runnable or clearly marked illustrative
- the tutorial does not drift into reference-style dumping
- the reader can finish with a concrete success state
