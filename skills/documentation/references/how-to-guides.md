# How-To Guides Path

Use this path when the reader already knows the basics and needs to solve a
specific problem quickly.

## Read First

- the exact workflow or command surface involved
- relevant config keys, flags, or examples
- troubleshooting signals from tests, docs, or code comments

## Writing Rules

- start with the problem to solve
- list prerequisites and assumptions
- solve the task in direct, ordered steps
- include verification and troubleshooting
- avoid broad conceptual teaching unless it is required to finish the task

## Recommended Sections

- problem statement
- prerequisites
- steps
- verification
- troubleshooting

## Validation Points

- the guide solves one concrete problem
- prerequisites are explicit
- steps do not assume hidden setup
- verification proves the problem is actually solved
