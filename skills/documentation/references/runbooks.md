# Runbooks Path

Use this path when documenting operational procedures, support actions, or
incident-response workflows.

## Read First

- operational scripts or commands
- monitoring and alerting references
- deployment or rollback procedures
- logs, health checks, and known failure modes

## Required Sections

- when to use this runbook
- required access and prerequisites
- pre-checks
- step-by-step procedure
- validation checks
- rollback or recovery steps
- escalation path

## Validation Points

- every operational command exists
- rollback is actionable, not aspirational
- the runbook states when to stop and escalate
- health checks and verification steps are concrete
