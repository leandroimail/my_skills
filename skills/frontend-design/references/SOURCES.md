# Sources

This file holds credits only. It contains no design guidance.

The original `SKILL.md` is covered by `LICENSE.txt` in the skill root. The reference files and the later additions to `SKILL.md` were written for this skill, informed by a comparison with the public skills below. Their ideas were restated in new wording; no passages were copied.

| Source | Author | License | What informed this skill |
|---|---|---|---|
| impeccable (`pbakaus/impeccable`) | Paul Bakaus | Apache-2.0 | Surface purposes (persuade, operate, read, experience), craft measures for type, color, and layout, motion timing, the list of generated-design reflexes, polish triage |
| ui-taste (`uizze.sh`) | Uizze | Apache-2.0; itself adapted from impeccable (Apache-2.0) and Appllama (MIT) | Preserve, extend, replace, or create; the frequency test for motion; token consistency checks; review severity levels |
| Web Interface Guidelines (`vercel-labs/web-interface-guidelines`) | Vercel Labs | MIT | Accessibility, form, focus, image, and locale items in the quality floor |
| minimalist-ui (`leonxlnx/taste-skill`, a version since removed from the repository) | leonxlnx | Not stated in the skill file | A few execution notes for minimal directions and semantic badges. Its fixed palette, font lists, and signature components were deliberately not adopted |

Accessibility thresholds follow WCAG 2.2 (W3C).
