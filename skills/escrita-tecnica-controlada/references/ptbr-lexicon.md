# pt-BR lexicon: avoid → use

Consult this file when a word is in doubt. The words and phrases in the tables are Portuguese because they are the object of the rules; the instructions are in English. Each row applies to one meaning of the word, shown in parentheses when there is more than one. Replace a word only when the word in your text has that meaning and the replacement keeps the same statement. "O requerimento foi protocolado" and "número efetivo de conexões" are correct and stay. A term inside the protected zone (code, command, interface label, quotation) stays as it is. Column headers: "Evite" = avoid, "Use" = use, "Faça" = do, "Diga" = say.

## 7. Noise: always cut (all levels)

- "Claro!", "Com certeza!", "Perfeito!", "Ótima pergunta", "Excelente observação"
- "Espero ter ajudado", "Fique à vontade para", "Qualquer dúvida, estou à disposição"
- "Vamos lá", "Vamos explorar", "Vamos entender"
- "Neste documento vamos abordar", "A seguir veremos", "Como mencionado anteriormente"
- "Em resumo, vimos que" no fim de seção curta
- "Vou analisar passo a passo", "Pensando de forma estruturada"
- "O futuro é promissor", "Só o tempo dirá"
- "Com base nas informações disponíveis", "Até onde sei": say which source you used and which one is missing. The phrase marks a limit of what you know, so the limit stays, in concrete form.

## 8. Noise: filler (`estrito` and `descritivo`)

| Evite | Faça |
|---|---|
| vale ressaltar, vale destacar, cabe mencionar, é importante notar | corte e diga o fato |
| além disso, ademais, outrossim (só para somar) | corte, ou "e" |
| nesse sentido, dessa forma, desse modo (sem causa) | corte, ou "por isso" se há causa |
| em suma, em síntese, em conclusão | corte |
| basicamente, simplesmente | corte |
| na prática, de certa forma, em geral | corte quando só enfeita. Fica quando limita a afirmação ("em geral, o job termina em 2 min" admite exceção). |
| sem dúvida, certamente, claramente, obviamente | mostre a evidência. Sem evidência, corte a palavra e mantenha a afirmação com o grau de certeza que a fonte dá. |
| quando se trata de X, no que diz respeito a X | escreva sobre X |
| no cenário atual, nos dias de hoje | a data ou o fato |
| estudos mostram, especialistas apontam, é sabido que | a fonte, ou corte |

"Apenas" and "somente" that restrict a quantity stay: "apenas um teste falhou" is a fact.

## 9. Noise: inflation (`estrito` and `descritivo`)

| Evite | Diga |
|---|---|
| robusto, resiliente | a qual falha o sistema sobrevive |
| abrangente, completo | o que está coberto |
| de ponta, de última geração, moderno | a versão ou a comparação |
| transparente, fluido, sem atrito | o que o usuário deixa de fazer |
| alavancar, potencializar, impulsionar | usar, ou "aumentar X em N" |
| crucial, fundamental, essencial, primordial | "obrigatório" se for requisito, ou corte |
| revolucionário, divisor de águas, inovador | o que mudou, com número |
| ecossistema, jornada, solução (como metáfora) | os componentes reais |
| não é só X, é Y | Se X e Y são fatos, os dois: "o serviço funciona como cache e como proxy". Se X é algo que ninguém afirmou, só Y. |
| escalável, performático, eficiente | o limite medido |

## 10. Brazilian variant

| Use | Não use |
|---|---|
| arquivo, usuário, tela, equipe, celular | ficheiro, utilizador, ecrã, equipa, telemóvel |
| cadastro, aplicativo, gerenciar, planilha, baixar | registo, aplicação (app), gerir, folha de cálculo, descarregar |
| contato, registro, fato, seção | contacto, registo, facto, secção |
| desempenho | performance |

The European variant is a variant choice, not a spelling error. For a reader in Portugal, invert the table. Columns: "Use" = use, "Não use" = do not use.
